# 场景三 / 场景四 数据字典

> Demo 演示系统数据规范 · V1.0 · 2026-11-10
> 场景三（图书馆霸座监测）与场景四（行为规范识别）点击运行时，
> 系统按本规范从 `demo/data/` 加载数据；文件缺失或字段不完整时，
> 自动注入内置兜底数据（scenarios.py 中 DEFAULT_* 常量），保证演示不中断。

## 一、场景三：seat_frames.json（霸座监测帧序列）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| camera_id | string | 是 | 摄像头编号，如 `lib-cam-03` |
| location | string | 是 | 区域名称，用于工单展示 |
| threshold_sec | number | 是 | 霸座判定阈值（秒），默认 1800（30 分钟） |
| check_interval_sec | number | 否 | 帧间隔（秒），展示用 |
| comment | string | 否 | 剧本说明，显示在执行步骤中 |
| seats | object | 否 | 座位元数据，key 为座位号 |
| seats.{id}.item | string | 否 | 遗留物品描述，如"书包和水杯" |
| seats.{id}.roi | int[4] | 否 | 座位监控区域 [x, y, w, h]（像素） |
| timeline | array | 是 | 帧序列，按时间升序 |
| timeline[].t | number | 是 | 相对起始时间的秒数 |
| timeline[].seats | object | 是 | 本帧各座位是否有遗留物品，true=有 |

**业务规则**：座位连续有物时长 ≥ threshold_sec 触发工单（一座一单）；连续丢检超过 3 帧计时复位。

## 二、场景四：behavior_frames.json（违规检测帧）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| camera_id | string | 是 | 摄像头编号 |
| location | string | 是 | 区域名称，用于事件展示 |
| comment | string | 否 | 剧本说明 |
| frames | array | 是 | 检测帧列表，按序消费 |
| frames[].frame_id | string | 是 | 帧标识 |
| frames[].detections | array | 是 | 本帧检出列表，可为空（对照帧） |
| frames[].detections[].label | string | 是 | 违规类别：`slippers`（穿拖鞋）/ `breakfast`（带早餐） |
| frames[].detections[].conf | number | 是 | 置信度 0~1 |
| frames[].detections[].bbox | int[4] | 是 | 人体框 [x1, y1, x2, y2]（像素） |
| frames[].detections[].face_ref | string | 是 | 人脸系统引用 ID，未匹配传 `unknown_face` |

## 三、场景四：face_db.json（虚拟人脸库）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| students | array | 是 | 学生列表 |
| students[].student_id | string | 是 | 学号，与 detections.face_ref 对应 |
| students[].name | string | 是 | 姓名 |
| students[].major | string | 是 | 专业 |
| students[].class_name | string | 是 | 班级 |

**匹配规则**：face_ref 命中 student_id → 定位到专业/班级；未命中 → 标记 `needs_review` 人工复核。

## 四、运行时注入保障

| 场景 | 数据文件 | 校验项 | 兜底策略 |
|---|---|---|---|
| 场景三 | seat_frames.json | 必填字段齐全、timeline 非空 | 注入内置双座位对照剧本 |
| 场景四 | behavior_frames.json | 必填字段齐全、frames 非空 | 注入内置 3 检出剧本 |
| 场景四 | face_db.json | students 非空且字段完整 | 注入内置 3 名学生 |

兜底注入时，执行步骤第一步会明确标注"数据文件不可用，已注入内置测试数据"，保证演示者对数据来源知情。
