## 7. 已知限制

| 限制 | 影响 | 后续计划 |
| --- | --- | --- |
| 视觉输入为关键点帧序列 | 需前置姿态估计服务 | 接入 RTMPose / YOLO-Pose 实时流 |
| SQLite 单机写入 | 高并发多校区场景受限 | 迁移 MySQL / PostgreSQL |
| ASR / LLM 默认离线模拟 | 研判深度有限 | 接入本地 Ollama 或校内大模型网关 |
| 占座服务需额外视觉依赖 | 默认不随主系统启动 | 按需部署，独立进程运行 |
| 演示账号为弱密码 | 不适合直接生产 | 部署即改密并禁用演示账号 |
