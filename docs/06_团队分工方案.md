## 3. 里程碑与协同节奏

| 阶段 | 目标 | 负责 |
| --- | --- | --- |
| 第 1 周 | 各组模块联调通过，演示场景全部可跑 | A/B/C 各自负责，D 组集成 |
| 第 2 周 | 全链路闭环演示 + 指标复核（响应时效、准确率口径） | D 组牵头，全员参与 |
| 第 3 周 | PPT/文档定稿、答辩彩排、回归测试与代码冻结 | D 组主责，A/B/C 复核各自章节 |

通用规则：

1. 代码提交前本地跑通 `pytest tests -q`（基线 78 passed + 1 skipped）；
2. 接口/配置变更必须同步更新 docs 对应章节；
3. 跨组契约（事件结构、推送报文、集成令牌）变更需四组组长会签；
4. 演示稳定性优先：所有外部依赖必须有降级路径（YOLO/ASR/LLM/人脸均可离线降级）。
